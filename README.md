# Nursing Bureau Online Platform  
![Build Status](https://img.shields.io/badge/build-passing-brightgreen) ![License](https://img.shields.io/badge/license-MIT-blue)

The **Nursing Bureau Online Platform** is designed to meet the increasing demand for accessible and reliable staffing solutions across healthcare and non-medical domains. It connects clients with qualified professionals, allowing users to easily find, book, and manage staff for their specific needs.

---

## 🏥 Overview

This platform allows:
- **Clients** (individuals, families, healthcare institutions) to hire staff for medical and non-medical needs.
- **Healthcare Staff** (nurses, physiotherapists, paramedics) and **Non-Medical Staff** (housekeepers, drivers, caregivers) to offer services and manage their availability.

---

## ✨ Key Features

- **👤 User Registration and Profile Management**: Clients and staff can create detailed profiles, including qualifications, availability, and personal information.
- **🔍 Search and Filter**: Clients can search for staff based on location, qualifications, and availability.
- **📅 Booking and Scheduling**: Schedule staff services with options for setting appointment times and durations.
- **📈 Real-Time Status Updates**: Displays the availability of staff (available/busy).
- **⭐ Ratings and Reviews**: Clients can rate and review staff for transparency and trust.
- **💬 Real-Time Communication**: Instant messaging between clients and staff.
- **💳 Secure Payment Processing**: Integrates with payment gateways like Google Pay, PayPal, and Paytm.
- **✅ Staff Verification**: Ensures credentials and qualifications are verified.
- **📍 Nearest Staff Location**: Uses Google Maps API to show the nearest available staff.

---

## 🩺 Platform Scope

This platform provides staffing solutions across two major categories:

### **Healthcare Staffing**:
- Registered Nurses (RNs)
- Physiotherapists
- Paramedics
- Elderly/Disabled Caregivers
- And more...

### **Non-Medical Staffing**:
- Housekeepers
- Cooks
- Drivers
- Personal Care Assistants
- Security Guards

---

## 🛠️ Technologies Used

- **Flutter**: For mobile app development with cross-platform compatibility.
- **Google Maps API**: To show the nearest available staff.
- **AJAX**: For real-time updates without page reloads.
- **Payment Integration**: Supports Google Pay, PayPal, Paytm for secure payments.

## 🚀 Installation

Follow these steps to set up the project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/Aniketps/Project_2024_Renew.git
    ```

2. Navigate to the project directory:

    ```bash
    cd Project_2024_Renew
    ```

3. Install dependencies and set up the environment:
   - **Flutter**: Ensure Flutter is installed and set up for mobile development.
   - **Back-end**: Set up the back-end server and database (details to be added later).

4. Run the project locally:
    ```bash
    flutter run
    ```
